# 🌲 Forest Survival – 3D Unity Game

A third-person **Forest Survival** game developed in **Unity**, featuring a fully 3D environment created using Unity’s **Terrain & Landscaping tools**. The game allows players to explore a forest landscape using a **Third-Person Perspective (TPP) controller**, with keyboard-based movement and mouse-controlled camera rotation for immersive surroundings exploration.

---

## 🎮 Game Overview

Forest Survival is a 3D exploration-based game where the player navigates through a natural forest environment. The focus of the project is on environment design, terrain generation, camera control, and third-person character movement.

**Objective:**  
Explore the forest terrain freely and experience smooth third-person navigation in a realistic environment.

---

## 🛠️ Built With

- Unity Engine (3D)
- C#
- Unity Terrain & Landscaping Tools
- Third-Person Controller
- Mouse & Keyboard Input System

---

## ✨ Features

- 3D forest environment created using Unity Terrain tools  
- Hills, plains, and natural land elevation using landscaping brushes  
- Third-Person Player (TPP) Controller  
- Keyboard-based movement (WASD)  
- Mouse hover to rotate camera and view surroundings  
- Smooth camera follow and rotation  
- Modular and clean C# scripting  

---

## 🎯 Controls

- **W / A / S / D** – Move character  
- **Mouse Movement** – Rotate camera / look around  
- **Mouse Hover** – View surroundings in third-person
